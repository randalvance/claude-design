# Rail

The 64px icon rail down the left edge of the app.

A `<nav class="pp-rail">` holding the mark (`pp-logo`), one `pp-rb` button per destination with an 18px icon and a `micro` label, a flexible `pp-sp` spacer and a Settings button at the bottom. Mark the current destination with `is-on` and `aria-current="page"`. A count goes in a `pp-nb` inside the button. You provide the icons (inline stroke SVG, see assets/Icons) and the labels; keep labels to one word so they fit 54px.
