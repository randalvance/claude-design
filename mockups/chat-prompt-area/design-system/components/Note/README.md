# Note

The user's message: a torn kraft note taped to the sheet.

A `pp-note` aligned to the end of the thread, at most 70% wide, with a `pp-tape` strip and the text inside `pp-note-in`. The torn edge is a clip-path; the shadow is a `drop-shadow` filter in `shadow` so it follows the tear. The note drops in from above in five steps. Text is `note` on `kraft`, pre-wrapped. You provide the text only; never put controls inside a note.
