# Inline

Inline text parts: code chips, wavy links, keyboard hints and hand-written annotations.

`pp-code` for an identifier, path or command inside a sentence. `pp-link` for links, wavy-underlined in `blue`. `pp-kbd` for a shortcut inside a field. `pp-dirtag` and `pp-hint` are hand-written annotations in `mute`: use them for context the eye can skip, never for instructions the user must read.
