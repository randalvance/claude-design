# Ledger

A ruled ledger sheet for file lists: a hand-written heading and dashed rows with plus and minus counts.

A `pp-ledger` sheet with an `<h3>` in Caveat and one `pp-lrow` per file: the path in mono (one line, ellipsis), then `pp-plus` and `pp-minus` counts in green and red bold. Rows divide with dashed hairlines. Use it for the Git tab and any path-plus-numbers list. Cap it at 760px.
