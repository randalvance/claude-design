# Button

The button family: a blue primary, sheet-coloured filters, a dashed utility button, round icon buttons and a hand-written link.

`pp-btn` is the one primary action on a screen (New): `blue` with a `shadow-blue-sm` hard shadow and white bold text. `pp-filt` is a sheet-coloured toggle; `is-on` highlights it. `pp-dashed` is a quiet utility button drawn as a dashed `bar` outline. `pp-ib` is a 30px round icon button for header actions; always give it an `aria-label`. `pp-lnk` is an inline hand-written link for a secondary choice inside a card ("use default"). All of them lift 1px on hover and show a solid `stroke-box` focus ring.
