# MaxStamp

The red MAX stamp on the composer card while Max effort is on.

A `pp-maxstamp` span positioned at the top right of a `pp-card is-max`: the word in `red` with a `stroke-box` border, `radius-3`, tilted 6°, on `stamp-ground` with multiply, landing with `pp-stamp`. It is decorative (`aria-hidden`): the effort button already states the level. The card border and shadow change with it (`max`, `shadow-max`). Nothing else in the composer glows or loops except the effort bars.
