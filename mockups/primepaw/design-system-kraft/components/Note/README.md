# Note

`kr-note` is a message from a person: a plain card of kraft paper with the paper texture, set square to the page and even all round, with no tape. Its kraft edge and shadow fall straight down, so it reads as one level card rather than a scrap pinned up. `kr-sticky` is a coloured note for a card on a board, in Caveat at 20px with dark ink in both themes. Set its colour with `--nc` and its lean with `--r`. At night it dims rather than inverting.
