# PermissionSlip

`kr-slip` is what a turn stops on when a tool needs your OK: a cream sheet (`kr-slip-in`) on an amber mat, the capsule's sibling. It holds still. Amber, the Needs you sticker and the badge on the session row are the signal, and nothing pulses.

The ask is handwritten in `kr-slip-q`, the tool kind sits beside it in `Courier` 11, and the command is `kr-slip-cmd`, or a file name and diff for an edit. `kr-slip-why` says in one sentence what will happen, and `kr-slip-tags` says what it touches. The actions are `kr-btn is-go` for Allow once, then plain `kr-btn` for Allow for this session and Deny, below a dotted tear line. You can always write in the composer instead, and `kr-slip-or` says so.

Your choice is struck with a `kr-stamp`: `is-green` APPROVED, `is-red` DENIED or YOLO, faded for SET ASIDE. A beat later the sheet folds to `is-stub`, one line with the stamp on it.
