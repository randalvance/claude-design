# QuestionSheet

When the agent has to ask, the questions go on one form in a `kr-slip`, all in view. There's no stepping through pages, so you can see how much is being asked and change an answer before sending.

Each `kr-q` has the question in `Fraunces` 15 and a `kr-q-hint` that names its topic and says pick one or pick any. Each `kr-qo` is a row with a tick box, round for pick one and square for pick any. A suggested choice gets a highlighted `recommended`, but nothing is ticked for you. The last row of each question is a `kr-qo-in` line for something else.

Send answers stays off until every question has an answer. You decide leaves it to the agent, and you can also just write in the composer. Like the permission slip, it gets a stamp and folds to `is-stub`, which lists each topic with its answer.
