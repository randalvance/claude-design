# Cork

`kr-cork` is the only surface that isn't paper or cardboard: a framed cork face for pinned paper. `kr-tack` is the red pin. Use it for pinned cards and nothing else: sticky notes on a Kanban board, and the knowledge base’s graph, which react-force-graph lays out on a canvas over the cork, where each note is a `kr-gcard` index card with its folder colour along the top, strung to the notes it touches with `kr-thread` in `kr-threads` (red for links, pale string for related, dashed ink for the parent). The note you are on takes the highlighter.
