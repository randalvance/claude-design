# LegalPad

`kr-pad` is a yellow ruled pad for a conversation that stays out of the session. `kr-pad-h` is its kraft binding with a perforated edge and a Caveat 20 title. `kr-pad-b` has a red margin and blue rules 22px apart, so body text sits on the lines. Questions are `kr-pad-q`, a small kraft note. Answers are plain text on the rules. `kr-pad-f` says what the pad does and doesn't touch.

The rules scroll with the text.
