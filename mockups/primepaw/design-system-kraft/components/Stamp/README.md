# Stamp

`kr-stamp` is ink on the paper, not a sticker: Courier at 10px in capitals, a 2px border in the same ink, always at `tilt-stamp`. `is-blue` and `is-red` change the ink. It multiplies into the paper by day and sits on top at night. Use it for a kind or a source, never for a live state.

`is-toggle` is a stamp you press, for a mode that changes how a whole session runs (YOLO). Off, it is a faded black outline, as if the stamp were nearly out of ink. On, it strikes down in red ink. It has `role="switch"` and `aria-checked`. The `inkstamp` SVG filter in the preview roughens its edges and leaves small gaps in the ink; add it to the page to get that look.
