Chips count or label things in one word or a number plus a noun; they never act.

**Provide:** `children`; optional `tone` (`ok` `warn` `err` `accent`) or `kind` (adds the kind-coloured dot).

- Count chips in a capsule are neutral except errors, which are `err` so they stay visible collapsed.
- `mono` for branch names, ids and endpoints.
- 20px tall, `radius-pill`, `chip` type style. Don't put more than one tone per chip.
